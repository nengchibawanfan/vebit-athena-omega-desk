# 名词解释与计算方法

给产品和后端看的口径。按页面逐条解释见 [页面名词.md](./页面名词.md)。接口字段、路径见 [API.md](./API.md)。

单位：数量为万枚，金额为万 USDT，价格为 USDT/枚。

---

## 1. 名词解释

| 名词 | 含义 |
| --- | --- |
| 真实用户 | 所内会买卖的对手盘。不含做市、金库、项目方、员工、LP |
| 做市账户 | 盘面用来报价、接用户买卖的账。用户买 = 做市卖，用户卖 = 做市买 |
| 持仓均价 | **只对真实用户说**。每个 UID 剩余存货的移动加权成本 |
| 库存成本 | **只对做市账户说**。自有库存的移动加权成本，不叫持仓均价 |
| 自有库存 `tokenOwn` | 做市账上真实有的代币 |
| 借入虚增 `tokenBorrowed` | 从用户侧借入、记在做市账上用来挂单周转的代币。不是买来的货 |
| 可周转库存 `tokenInv` | `tokenOwn + tokenBorrowed`。挂单用这个数 |
| 真实 USDT `cashTrueU` | 做市账上真实有的 USDT |
| 借入 USDT `cashBorrowedU` | 从用户侧借入、记在做市账上用来挂单的 USDT |
| 可周转 USDT `cashU` | `cashTrueU + cashBorrowedU` |
| 入库 | 货进来：买入成交，或充值到账 |
| 出库 | 货出去：卖出成交，或提现。做市还有还款 |
| 现价 | 当前盘面价。充值入库用到账时的现价 |
| 偏离% | `(现价 − 成本) / 成本 × 100`。正数 = 现价高于成本 |

买卖方向整站同一套，且两边是同一批成交：

```
用户买入 = 做市卖出
用户卖出 = 做市买入
```

**做市账户的交易相关统计，只计与真实用户的成交。** 自成交（做市 UID 自己买自己）、内部调仓、与金库 / 项目方 / 员工 / LP 的成交，一律不进做市买 / 卖 / 均价 / 人数 / 笔数 / 盈亏。库存、余额、虚增仍按账上实际滚，那些不是交易统计。

## 2. 共同算法：移动加权

持仓均价和库存成本是同一套算法：

- 货进来：按这次的入库价加权进成本
- 货出去：只减数量，**不重算成本**

```
入库后成本 = (旧成本 × 旧数量 + 本次入库量 × 入库价) / (旧数量 + 本次入库量)
出库后数量 = max(0, 旧数量 − 出库量)     // 成本不变
```

| 事件 | 入库价 |
| --- | --- |
| 买入成交 | 成交价 |
| 充值到账 | 到账时现价 |

差别只在记账对象：用户按每个 UID 的剩余持仓；做市只算自有库存，虚增 / 还款不进成本。

---

## 3. 真实用户持仓均价

对象：每个真实 UID 的所内剩余持仓。不含做市 / 金库 / 项目方 / 员工 / LP。

| 事件 | 数量 | 持仓均价 |
| --- | --- | --- |
| 买入成交 | + | 按成交价加权入库 |
| 充值到账 | + | 按到账现价加权入库 |
| 卖出成交 | − | 只减数量，不重算 |
| 提现 | − | 只减数量，不重算 |

```
入库后均价 = (旧均价 × 旧数量 + 本次入库量 × 入库价) / (旧数量 + 本次入库量)
出库后数量 = max(0, 旧数量 − 出库量)     // 均价不变
持仓均价   = Σ(该 UID 剩余数量 × 入库价) / Σ剩余数量
浮盈亏(万) = 剩余数量(万) × (现价 − 均价)
偏离%      = (现价 − 均价) / 均价 × 100
```

群体持仓均价 = 各 UID 按剩余数量加权。筹码分布、价格台阶、总览上的「用户均价」都用这个数。

---

## 4. 做市账户库存成本

算法与第 3 节相同，记账对象是做市**自有库存** `tokenOwn`。

可周转库存 `tokenInv = tokenOwn + tokenBorrowed` 用来挂单，**虚增不进成本**。

| 事件 | 数量 | 库存成本 |
| --- | --- | --- |
| 买入成交（仅对真实用户） | 自有 + | 按成交价加权入库 |
| 充值到账 | 自有 + | 按到账现价加权入库 |
| 卖出成交（仅对真实用户） | 可周转 −（先虚增、再自有） | 碰到自有只减数量，不重算 |
| 提现 | 自有 − | 只减数量，不重算 |
| 虚增（借入） | `tokenBorrowed` + | 不动成本 |
| 还款 | `tokenBorrowed` − | 不动成本 |

```
入库后成本 = (旧成本 × 旧自有库存 + 本次入库量 × 入库价) / (旧自有库存 + 本次入库量)
出库后自有 = max(0, 旧自有 − 出库量)     // 成本不变
库存成本   = 自有剩余存货的移动加权成本
偏离%      = (现价 − 库存成本) / 库存成本 × 100
```

不要把虚增按 0 或现价混进加权：按 0 会把成本砸垮，按现价会让成本和现价缠在一起。总览 / 价格台阶 / 做市今日的库存成本都是这个自有口径。

---

## 5. 对照

| | 真实用户持仓均价 | 做市账户库存成本 |
| --- | --- | --- |
| 算法 | 移动加权 | 同一套 |
| 对象 | 每个 UID 剩余持仓 | 做市自有库存 |
| 买入 / 充值 | 加权入库 | 加权入库 |
| 卖出 / 提现 | 只减数量 | 只减数量 |
| 虚增 / 还款 | 没有这两项 | 不进成本 |
| 页面用语 | 只说持仓均价 | 只说库存成本 |

## 6. 做市账户交易统计

只计 **做市 UID ↔ 真实用户**。自成交、内部调仓、与金库等成交一律不算。

```
做市卖出 = 用户买入
做市买入 = 用户卖出
```

两边必须同一批成交，数字相等（四舍五入除外）。

进这套口径的：买 / 卖数量、金额、均价、人数、笔数、对倒量、交易盈亏、存货浮盈、今日盈亏、USDT 净增加、代币净变动（交易口径）、成交明细、分时买卖、机器人今日成交额。

不进这套口径的：库存、余额、虚增、还款。那些按账上实际滚。机器人「自成交」可以开着撑盘口，但不要把那部分量算进上面任何一项。
