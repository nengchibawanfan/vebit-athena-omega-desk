# 页面名词与计算口径

按现网每一个页面，解释屏幕上出现的名词：是什么、怎么算。给产品和后端对口径用。

单位全文统一：数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。金额 = 数量 × 价格。

买卖方向全文同一套，且两边是同一批成交：

```
用户买入 = 做市卖出
用户卖出 = 做市买入
```

内部账（做市、金库、项目方、员工、LP）一律不算「真实用户」。

**做市账户的交易相关统计，只计与真实用户的成交。** 自成交、内部调仓、与金库等成交不进做市买 / 卖 / 均价 / 人数 / 笔数 / 对倒 / 盈亏 / 成交明细。机器人配置里的「自成交」只撑盘口，不算进这些数。库存、余额、虚增仍按账上实际滚。

成本算法全文共用，详见 [名词解释.md](./名词解释.md)：货进来按入库价加权，货出去只减数量、不重算成本。真实用户叫 **持仓均价**；做市只对自有库存叫 **库存成本**，借入虚增不进成本。

## 全文共用

这些词在很多页重复出现，先定死。后面各页只写本页特有的，或指出「同总览」。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 真实用户 | 所内会买卖的对手盘 | 持仓或成交的 UID，去掉做市 / 金库 / 项目方 / 员工 / LP |
| 做市账户 | 盘面报价、接用户买卖的账 | 机器人配置里的做市 UID |
| 金库等 | 不直接买卖的内部账 | 金库 / 项目方 / 员工 / LP |
| 现价 | 当前盘面价 | 最近一笔成交价；没有成交用最新中间价 |
| 持仓均价 | 真实用户剩余存货成本 | 每个 UID 移动加权；群体 = 按剩余数量加权。买入/充值加权入库，卖出/提现只减数量 |
| 库存成本 | 做市自有库存成本 | 只滚自有库存。对真实用户买入/充值加权；卖出先扣虚增再扣自有，碰到自有只减数量；虚增/还款/自成交不进成本 |
| 偏离% | 现价相对成本偏了多少 | `(现价 − 成本) / 成本 × 100`。正数 = 现价高于成本 |
| 自有 | 账上真实有的货或 USDT | 做市：自有库存 / 真实 USDT |
| 借入虚增 | 从用户侧借入、记在做市账上用来挂单的 | 不是买来的货，不进库存成本 |
| 可周转库存 | 做市现在能拿去挂单的代币 | 自有 + 借入虚增 |
| 做市账户余额 / 可周转 USDT | 做市现在能拿去挂买单的 USDT | 真实 USDT + 借入 USDT |
| 沉睡 | 很久没成交的持仓 | 距该 UID 该币最近一笔成交 ≥ 页面配置的天数（默认 30 天） |
| 活跃 | 还在成交的持仓 | 未沉睡 |
| 万 | 代币数量单位 | 1 万 = 10,000 枚 |
| 万USDT | 金额单位 | 1 万 USDT = 10,000 USDT |
| 自成交 | 做市 UID 自己买自己，撑盘口 | 机器人可开。**不进**做市交易统计 |

做市当日盈亏三件套（今日页、历史区间、机器人页共用）。下面的买 / 卖 **只含对真实用户**，不含自成交：

```
对倒量     = min(买入量, 卖出量)
交易盈亏   = 对倒量 × (均卖 − 均买)
净变动     = 买入量 − 卖出量
存货浮盈   = 净变动 × (现价 − 标记成本)
             净买入用均买做标记成本，净卖出用均卖
今日盈亏   = 交易盈亏 + 存货浮盈
```

存货浮盈只盯 **今天对用户的净头寸**，不含开盘前已经在账上的库存，也不含自成交。全部库存相对库存成本的偏离，看「库存成本 · 偏离」，不要和存货浮盈混成一个数。

## 1. 总览 `/`

操盘第一屏：自己有多少子弹、对手有多少货、今天买卖结果、货在哪、有没有警报。

### 顶部三行

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 建议动作（右上角徽章） | 这一刻更像该拉还是该砸 | 用户还在净买且偏离不高 → 可拉、卖出；偏离已经很高 → 停拉；用户在净卖且下方买墙够厚 → 可砸、买入；否则别动 |
| 现价 | 盘面价 | 见全文 |
| 做市账户库存成本 · 偏离 | 你自己货的成本，现价相对它偏了多少 | 库存成本见全文；偏离 = `(现价 − 库存成本) / 库存成本 × 100` |
| 真实用户持仓均价 · 偏离 | 对手手里货的均价，现价相对它偏了多少 | 群体持仓均价；偏离 = `(现价 − 持仓均价) / 持仓均价 × 100` |

### 四张主卡

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 做市账户余额 | 做市账上能用来挂买单的 USDT | 真实 USDT + 借入 USDT |
| 　自有 · 借入虚增 | 余额拆开 | 真实有的 USDT / 借入的 USDT |
| 可周转库存 | 做市账上能拿去挂单的代币 | 自有库存 + 借入虚增 |
| 平台用户USDT | 真实用户手里的现金 | 所有真实 UID 的 USDT 余额合计 |
| 平台用户代币 | 真实用户手里的该币 | 所内该币余额 − 做市库存 − 金库等 |
| 　活跃 · 沉睡 | 用户代币再拆 | 未沉睡 UID 的持仓合计 / 沉睡 UID 的持仓合计 |

### 今日交易情况（做市视角）

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 卖出 数量 / 金额 / 均价 | 做市把货卖给真实用户 | 当日对真实用户卖出合计；金额 = 数量 × 均价；均价 = 卖出成交额 / 卖出量。不含自成交 |
| 买入 数量 / 金额 / 均价 | 做市从真实用户手里把货买回来 | 当日对真实用户买入合计，算法同上。不含自成交 |
| USDT 净增加 | 这一天对用户成交让做市 USDT 多了还是少了 | 卖出金额 − 买入金额。正数 = 货换成了钱 |
| 代币净变动 | 这一天对用户成交让做市库存多了还是少了 | 买入量 − 卖出量。正数 = 货变多 |
| 平均价格 | 净头寸是按什么价换的 | `USDT净增加 / 代币净变动`。净变动为 0 时显示 `--` |

### 价格台阶预览

七档：+20% / +10% / +5% / 现价 / −5% / −10% / −20%。完整算法见「价格台阶」页。这里只预览挂单厚度。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 台阶 | 相对现价的位置 | 固定七档 |
| 价格 | 这一档对应的盘面价 | `现价 × (1 + 台阶%)` |
| 挂单 | 这一档自己的真实挂单量 | 本档累积 − 更靠近现价那一档的累积。现价档为 0 |
| 挂单金额 | 上一格换成 USDT | 挂单量 × 该档价格（或挂单价合计） |
| 累积 | 从现价扫到这一档会碰到的真实挂单 | 往上累卖单（卖墙），往下累买单（买墙）。现价为 0 |

### 供给位置

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 所内流通 | 已经在交易所、能成交的货 | 活跃用户代币 + 沉睡用户代币 + 做市库存 |
| 活跃 / 沉睡 / 做市 | 所内流通三截 | 见上；做市 = 可周转库存 |
| 链上仓库 | 还在链上、本所成交不到的货 | 总流通 − 所内流通 |
| 可充回 | 链上仓库里相对活跃、随时可能充进来的 | 未锁仓、近期还有过充提或转账的量（没有链上活跃标记时用估计） |
| 沉睡（链上） | 链上长期不动的 | 链上仓库 − 可充回 |

链上不能成交。货要充进所内，才变成可卖供给。

### 报警

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 时间 / 级别 / 内容 | 待处理警报摘要 | 与「报警」页同一套。级别：紧急 / 预警 / 关注 |

## 2. 价格台阶 `/ops/ladder`

看：到某个价，外面挂了多少单、用户可能再卖多少、盘口偏买还是偏卖、有没有大单。

### 页顶配置

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 近端档位 | 算 OBI / 买盘卖盘时看多少档 | 10 / 15 / 20，默认 10 |
| 预警 \|OBI\| | 厚度失衡阈值 | 真实 OBI 绝对值 ≥ 该值视为失衡，默认 0.4 |
| 偏离预警 | 用户均价压力区 | \|现价相对持仓均价的偏离\| ≥ 该值，默认 20% |
| 大单阈值 | 多大算盘口大单 | 单笔成交 ≥ 该值（万枚），默认 50 |

### 状态行

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 现价 | 盘面价 | 同总览 |
| 用户均价 · 偏离 · 压力区 | 对手成本，现价离它多远 | 与总览「真实用户持仓均价」同一批人。进压力区 = \|偏离\| ≥ 偏离预警 |
| 做市库存成本 · 偏离 | 你自己货的成本 | 同总览 |

### KPI

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 用户持有流通代币 | 真实用户手里的该币 | 同总览「平台用户代币」 |
| +10% 卖墙 | 现价拉到 +10% 会吃到的真实卖单 | 现价到 +10% 这一档的真实用户卖单合计（累积） |
| −10% 买墙 | 现价砸到 −10% 会打到的真实买单 | 现价到 −10% 的真实用户买单合计 |
| 真实OBI | 近端真实用户买盘相对卖盘的厚度 | `(真实买盘 − 真实卖盘) / (真实买盘 + 真实卖盘)`。必须剔除做市自挂 |
| 　含做市 | 把做市挂单算进去的 OBI | 同上，但不剔除做市。报价只看真实 |
| 持仓均价 | 真实用户加权均价 | 同总览 |
| 近端买盘 | 前 N 档真实买单 | 近端档位内、真实 UID 的买单合计 |
| 　含做市 | 近端买单含做市 | 不剔除做市 |
| 近端卖盘 | 前 N 档真实卖单 | 对称 |
| 价格偏离 | 现价相对用户均价 | `(现价 − 持仓均价) / 持仓均价 × 100` |
| 　浮盈 · 浮亏 | 用户筹码里赚钱/亏钱的占比 | 均价 < 现价的持仓 / 总持仓；浮亏 = 100% − 浮盈 |
| 净买入 | 当日大单里用户净买了多少 | 大额买入量 − 大额卖出量。用户买 = 你在卖出 |
| 　成交额 | 大单买+卖 | 大额买入量 + 大额卖出量 |
| 待处理 | 大单相关未处理警报 | 状态不是「已处理」的条数 |
| 　红色 | 其中标红的 | 通常是特别大的单 |
| 大单笔数 | 过阈值的成交笔数 | 真实 UID、≥ 大单阈值、不含做市 |
| 　买 · 卖 | 大单方向拆开 | 用户买 / 用户卖的笔数 |

### 台阶明细

七档固定。现价是行为起点，这一档挂单为 0。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 台阶 / 价格 | 相对现价的位置和对应价 | `现价 × (1 + 台阶%)` |
| 真实挂单 | 从现价扫到这一档会碰到的真实单 | 往上：卖单累积（卖墙）。往下：买单累积（买墙）。现价 = 0 |
| 金额（挂单旁） | 这些挂单值多少钱 | 挂单量 × 档位价 |
| 预估卖出 | 价格到了这一档，用户持仓里大概会再卖掉多少 | 不是挂单。对每个真实 UID：用该档价格相对他的持仓均价算盈亏%，再按下面的卖出率 × 剩余仓位，最后加总 |
| 预估卖出金额 | 上一格换成 USDT | 预估卖出 × 该档价格 |
| 盈亏范围色条 | 预估卖出来自哪些盈亏带 | 按浮盈/浮亏分档：≥30%、20–30%、10–20%、5–10%、0–5%。色条占比 = 该带预估卖出 / 本档预估卖出合计 |

预估卖出率（浮盈、浮亏用绝对值，同一条曲线）：

```
x = |该档价相对该 UID 持仓均价的偏离%|
x = 0     → 卖 0
x ≤ 5%    → 从 0 线性到 10% 仓
x ≤ 10%   → 从 10% 线性到 20% 仓
x ≤ 30%   → 从 20% 线性到 30% 仓
x > 30%   → 卖 30% 仓
```

口算：浮盈/浮亏 5% 约卖 10% 仓，10% 约卖 20%，30% 约卖 30%。

### 真实用户挂单

当前未成交的真实用户单。同价多笔不合并，会标「同价 n笔」。≥ 大单阈值高亮。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 价格 | 挂单价 | 订单上的价 |
| 方向 | 买或卖 | 用户买 = 你卖出；用户卖 = 你买入 |
| 数量 | 还没成交的量 | 剩余量，万枚 |
| 至该价累计 | 从盘口扫到这个价会碰到多少 | 同一方向、价格不劣于该笔的所有真实挂单数量之和（同价几笔都算进去） |
| 账户 | 谁挂的 | UID 或脱敏展示 |
| 挂单时间 | 何时挂上 | 订单时间 |

### 大单明细

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 时间 / UID / 标签 | 谁、何时打的大单 | 当日真实成交，数量 ≥ 大单阈值 |
| 方向 | 买或卖 | 用户方向 |
| 金额(万) | 成交数量 | 万枚 |
| 约合USDT | 这笔值多少钱 | 数量 × 成交价 |

## 3. 做市账户今日 `/ops/dump`

自己今天买卖、库存、余额。点历史日期进来时，词改成「当日」，算法按那一天。

顶部现价 / 库存成本 / 用户均价：同总览。

### KPI

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| {代币}余额 | 可周转库存 | 自有 + 借入虚增 |
| {USDT}余额 | 做市账户余额 | 真实 USDT + 借入 USDT |
| 交易盈亏 | 今天对用户来回做成的价差 | `min(买,卖) × (均卖 − 均买)`。买/卖只含对真实用户 |
| 存货浮盈 | 今天对用户净头寸按现价盯市 | 见全文三件套。不是全部库存减库存成本 |
| 今日盈亏 | 上面两项之和 | 交易盈亏 + 存货浮盈 |

### 做市账户明细（每个 UID）

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| UID / 备注 | 哪个做市账 | 机器人配置 |
| 状态 | 机器人是否在挂 | 运行中 / 离线 / 已停止 / 告警 |
| 代币自有 / 代币借入 | 该 UID 库存拆开 | 自有 / 虚增 |
| 做市账户余额 | 该 UID 可周转 USDT | 真实 + 借入 |
| 真实余额 / 借入金额 | USDT 拆开 | |
| 今日买 / 今日卖 | 该 UID 当日对真实用户成交量 | 做市方向，万枚。不含自成交 |
| 净买入 | 该 UID 对用户净拿货还是出货 | 买 − 卖 |
| 交易盈亏 / 浮盈 | 该 UID 的三件套 | 算法同 KPI，只算这一只 UID 对真实用户的成交 |

### 交易情况

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 卖出 数量 / 金额 / 均价 / 人数 / 笔数 | 做市卖给真实用户 | 数量、金额、均价同总览；人数 = 对面真实 UID 数；笔数 = 对用户卖出笔数。不含自成交 |
| 买入 数量 / 金额 / 均价 / 人数 / 笔数 | 做市从真实用户买回 | 对称 |
| USDT 净增加 / 代币净变动 | 同总览 | 卖出金额 − 买入金额；买入量 − 卖出量 |
| 买入均价 / 卖出均价 / 交易均价 | 净头寸对应的那一侧均价 | 净买入（货变多）显示买入均价；净卖出显示卖出均价；净变动为 0 显示 `--` |

### 交易对手方

表里的买/卖是 **用户方向**（用户买 = 你卖）。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 散户 / 聪明钱 | 打了该标签的真实用户 | 标签规则见「对手盘」 |
| 真实用户 | 全部真实对手 | 散户 + 聪明钱 + 其它真实标签 |
| 买 / 卖 / 净 | 用户买、用户卖、净买入 | 买 − 卖。正数 = 用户在接你的货 |

### 图和成交明细

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 做市库存图 | 库存随时间 | 小时末可周转库存 |
| 自有 vs 借入虚增 | 库存饼图 | 当前自有 / 虚增 |
| 今日K线 | 价格、库存成本、净买卖 | 柱在零上 = 该小时做市对用户净买入；线为现价和库存成本 |
| 今日分时 | 小时卖出 / 买入 | 做市对真实用户，万枚；全天合计 = KPI 卖出/买入。不含自成交 |
| 成交明细 方向 | 做市视角 | 卖出 / 买入。只列与真实用户的成交 |
| 数量 / 价格 / 金额 | 这一笔 | 金额 = 数量 × 价格 |
| 对手 UID / 标签 | 对面是谁 | 真实用户 UID 及其标签 |

## 4. 做市账户历史 `/ops/dump/history`

上币以来每一天，点日期进当日。算法与今日相同，只是窗口从「今天」变成「全部交易日」。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| {代币}余额 / {USDT}余额 | 期末库存和 USDT | 最后一天日终，拆法同今日 |
| 真实交易量 | 区间里对用户来回做的部分 | `min(区间买入合计, 区间卖出合计)`。买/卖只含对真实用户 |
| 交易盈亏 / 存货浮盈 / 盈亏 | 区间三件套 | 用区间买/卖合计 + 期末现价，公式同今日 |

## 7. 筹码分布 `/desk/users/chips`

真实用户现在手里的货：什么成本、谁在赚钱、谁睡着了。不含做市 / 金库等。

### 配置

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 沉睡判定 | 几天没成交算沉睡 | 默认 30 天。超过 N 天无该币成交 |
| 体量分档 | 沉睡里多大算大户 | 持仓 ≥ N 万算大户一类，默认 50 万 |

### KPI

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 持仓均价 | 群体加权成本 | `Σ(UID剩余数量 × 该UID均价) / Σ剩余数量` |
| 　中位 | 一半筹码在这个成本以下 | 按成本从低到高累加持仓，到 50% 时那个 UID 的均价 |
| 现价 · 偏离% | 现价相对持仓均价 | 同全文偏离 |
| 浮盈筹码 | 均价低于现价的货 | 条件：该 UID 均价 < 现价。给出占比、数量、人数 |
| 浮亏筹码 | 均价不低于现价的货 | 均价 ≥ 现价。占比 + 数量 + 人数 |
| 活跃筹码 | 未沉睡的持仓 | 数量 + 人数 |
| 持仓用户 | 有仓人数 | 余额 > 0 |
| 密集成本区 | 持仓量最大的均价区间 | 直方图里数量最多的那一档 |
| 人数最多区间 | 人数最多的均价区间 | 可以和密集区不是同一档 |
| 沉睡筹码 / 沉睡占比 / 沉睡用户 | 睡着的货 | 占比 = 沉睡数量 / 用户代币合计 |

### 收益率分档

按 `(现价 − 该UID持仓均价) / 均价`，六档，不要用深套/浅套/小赚/大赚。

| 档位 | 条件 |
| --- | --- |
| 盈利 0–20% | 0 ≤ 偏离 < 20% |
| 盈利 20–50% | 20% ≤ 偏离 < 50% |
| 盈利 ≥50% | 偏离 ≥ 50% |
| 亏损 0–20% | −20% < 偏离 < 0 |
| 亏损 20–50% | −50% < 偏离 ≤ −20% |
| 亏损 ≥50% | 偏离 ≤ −50% |

人数 = 落入该档的 UID 数。持仓 = 这些 UID 的剩余合计。占比 = 持仓 / 用户代币合计。

### 持仓均价分布 / 分档表

把每个 UID 的持仓均价打进价格区间（柱）。虚线是现价，点线是群体持仓均价。现价左边的区间是浮盈。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 持仓均价（区间名） | 这一档成本范围 | 例如 `0.85–0.90` |
| 人数 / 持仓 / 占所内 | 落入该档 | 占所内 = 该档持仓 / 用户代币合计 |
| vs现价 | 档中点相对现价 | `(现价 − 档中点) / 档中点 × 100`。正数 = 现价更高 = 这档在赚钱 |
| 状态 | 浮盈 / 浮亏 / 跨现价 | 整档在现价下方 → 浮盈；整档在现价上方 → 浮亏；现价劈开这一档 → 跨现价 |

### 沉睡分档明细

只统计沉睡 UID，按持仓体量再切：

- 大户：≥ 体量阈值
- 中额：阈值/5 ～ 阈值
- 小额：< 阈值/5

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 占沉睡 | 该档占全部沉睡筹码 | 该档数量 / 沉睡合计 |
| 占所内 | 该档占全部用户代币 | 该档数量 / 用户代币合计 |

### 持仓集中度

前 5 名 UID 持仓 + 「其他用户」。看筹码是不是集中在少数人手里。

### 用户筹码明细

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 用户ID | UID | |
| 持仓 | 所内剩余 | 万枚 |
| 持仓均价 | 该 UID 移动加权成本 | 见全文 |
| 均价区间 | 落在哪一档直方图 | 与分档表同一套 |

库存、盈亏、成交口径与「做市账户今日」对齐：交易相关数字只计与真实用户的成交。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 运行机器人 | 在线数 / 已配置 UID | 配置了、总开关开、该 UID 运行中、心跳正常 |
| 做市库存 | 可周转库存 | 自有 · 借入虚增。安全带：占所内流通 40%–60% 为安全区间，低于偏低、高于偏高 |
| 今日盈亏 | 三件套合计 | 交易盈亏 + 存货浮盈。不含期初库存 |
| 今日成交额 | 对真实用户买+卖 | 数量；第二行 × 现价 = 万 USDT。不含自成交 |
| 买卖成交比 | 买成交 / 卖成交 | 只计对真实用户。≥1 = 净在买入；<1 = 净在卖出 |
| 报价质量 均价差 | 买卖一价差 | 各 UID 价差平均，单位 bps（1 bps = 0.01%） |
| 　覆盖 | 近端档位被自有挂单盖住的比例 | % |
| 近24小时做市库存 | 库存带图 | 横轴小时；带为配置里的库存低/高（展示用，默认 20%–80%） |
| 买/卖成交与累计盈亏 | 小时对用户成交和累计 PnL | 万枚；盈亏万 USDT。不含自成交 |
| 报价价差 | 小时价差 | bps |

### 机器人账户表

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 角色 | 主报价 / 备用挂价 / 辅助档 | 配置顺序，仅展示 |
| 策略 | 这只 UID 用哪套参数 | 做市报价 / 护盘托价 / 库存回归 / 跟价推进 / 仅挂不吃 |

| 今日PnL | 该 UID 今日盈亏 | 三件套，只计对真实用户 |
| 买成交 / 卖成交 | 当日对真实用户量 | 万枚。不含自成交 |
| 价差bps | 该 UID 当前价差 | |
| 撤单率 | 撤单 / 挂单 | % |
| 心跳 | 延迟和最近一次回报 | 如 `16ms · 8秒前`；停了显示已停止；没回报显示失联 |

## 11. 机器人配置 `/robots/config`

只存在浏览器，不单独请求后端。保存后，「运行状态」按这份参数跑。

| 名词 | 含义 | 怎么算 / 怎么用 |
| --- | --- | --- |
| 全局开 / 全局停 | 总开关 | 关掉则所有 UID 停止挂单 |
| 运行 n/m | 运行中的 UID / 已配置 UID | |
| 做市账户 UID | 哪些账拿去做市 | 添加到内部账户 type=做市 |
| 启停 | 这一只 UID 是否运行 | 总开关关掉时不能单独开 |
| 策略 | 这一只用哪套参数 | 五种策略各有自己的挂单 / 自成交 / 报价 |
| 自成交 | 这一只是否允许自成交撑盘口 | 开了也不进做市交易统计 |

五种策略含义：

| 策略 | 做什么 |
| --- | --- |
| 做市报价 | 买卖双边挂单，跟着现价 |
| 护盘托价 | 买盘加厚，卖盘减薄 |
| 库存回归 | 库存偏高就卖、偏低就买 |
| 跟价推进 | 现价跟着目标台阶走 |
| 仅挂不吃 | 报价但不主动吃单 |

### 挂单配置

百分比相对现价。`0.1` = 千分之一 = 0.1%。

| 名词 | 含义 |
| --- | --- |
| Bid 买 / Ask 卖 | 买盘规则 / 卖盘规则，可多条 |
| 最小百分比 / 最大百分比 | 这档挂单离现价多远 |
| 最小/最大每单数量 | 每笔挂单金额，单位 **USDT（不是万）** |
| 挂单数量 | 这一条规则挂几档 |
| 挂单间隔 | 相邻两笔挂单间隔，毫秒 |

### 自成交配置

只撑盘口量，**不进**做市买 / 卖 / 均价 / 盈亏 / 成交明细。

| 名词 | 含义 |
| --- | --- |
| 最小成交时间间隔 | 两次自成交至少隔多少毫秒 |

### 报价配置

| 名词 | 含义 |
| --- | --- |
| 价差类型 | 固定 或 百分比 |
| 买盘价差 / 卖盘价差 | 买一、卖一离中间价多远 |
| 盘口最小/最大距离 | 挂单价与现价的距离范围 |
| 价格随机比例 | 挂单价允许抖动的比例 |

另一本账：金库 / 项目方 / 员工 / LP。不能直接拿去买卖。可周转的代币和 USDT 在做市账户。做市 UID 在本页只能看、不能从这里删。

## 16. 跨页对照（避免算重、算反）

同一件事在不同页出现时，数字必须相同。

| 这件事 | 出现在 | 必须一致 |
| --- | --- | --- |
| 做市可周转库存、自有、虚增、USDT 拆账 | 总览、做市今日、金库等、机器人 | 同一时刻同一套 |
| 做市今日买/卖/均价/USDT净增加 | 总览「今日交易情况」、做市今日、机器人成交 | 同一天同一套；只计与真实用户 |
| 用户持仓均价、偏离 | 总览、价格台阶、筹码分布 | 同一批真实 UID |
| 做市库存成本、偏离 | 总览、价格台阶、做市今日 | 只滚自有库存 |
| 平台用户代币 | 总览、真实用户今日、价格台阶「用户持有流通代币」、筹码分布合计 | 所内真实用户持仓 |
| 用户买 = 做市卖、用户卖 = 做市买 | 做市今日 vs 真实用户今日 | 同一批「做市↔真实用户」成交，数字必须相等。自成交、内部调仓都不进 |
| 历史最后一天 | 各历史页期末 | 等于对应「今日」页 |

方向不要反：用户净买入为正，表示用户在拿货、你在出货。做市代币净变动为正，表示做市库存增加（你在买回）。USDT 净增加为正，表示做市钱变多（你在卖出）。
