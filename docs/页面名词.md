## 总览

操盘第一屏：自己有多少子弹、对手有多少货、今天买卖结果、货在哪、有没有警报。路径 `/`。

本页单位：数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。金额 = 数量 × 价格。

本页里的「真实用户」= 所内会买卖的对手盘 UID，去掉做市 / 金库 / 项目方 / 员工 / LP。「做市账户」= 机器人配置里拿来报价、接用户买卖的 UID。

```
用户买入 = 做市卖出
用户卖出 = 做市买入
```

做市买 / 卖只计与真实用户的成交。自成交、内部调仓、与金库等成交不进本页「今日交易情况」。

### 顶部三行

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 建议动作（右上角徽章） | 这一刻更像该拉还是该砸 | 用户还在净买且偏离不高 → 可拉、卖出；偏离已经很高 → 停拉；用户在净卖且下方买墙够厚 → 可砸、买入；否则别动 |
| 现价 | 当前盘面价 | 最近一笔成交价；没有成交用最新中间价 |
| 做市账户库存成本 · 偏离 | 做市自有库存的成本，现价相对它偏了多少 | 只滚自有，不滚虚增。自有 > 0 是买入成本，自有 < 0 是卖出成本，自有 = 0 不显示。偏离 = `(现价 − 库存成本) / 库存成本 × 100`。正数 = 现价高于成本 |
| 真实用户持仓均价 · 偏离 | 对手手里货的均价，现价相对它偏了多少 | 见下「持仓均价怎么滚」。偏离 = `(现价 − 群体持仓均价) / 群体持仓均价 × 100` |

本页「真实用户持仓均价」是群体数：

```
每个真实 UID：买入/充值按入库价加权，卖出/提现只减数量、不重算，数量不小于 0
入库后均价 = (旧均价 × 旧数量 + 本次入库量 × 入库价) / (旧数量 + 本次入库量)
入库价：买入 = 成交价；充值 = 到账时现价
出库后数量 = max(0, 旧数量 − 出库量)
群体持仓均价 = Σ(该 UID 剩余数量 × 该 UID 均价) / Σ剩余数量
```

本页「做市账户库存成本」只滚自有：

```
可周转库存 = 自有 + 虚增
虚增：只有再介入才加，只有还款才减；买卖充提永远不动
自有：买卖、充提只改这一栏，可以为负

自有 > 0：买入成本。买/充值按入库价加权；卖/提现只减数量，成本不变
自有 = 0：没有成本，不显示偏离
自有 < 0：卖出成本。卖/提现按出库价加权；买/充值只补缺口，卖出成本不变

自有 > 0 时买入 / 充值：
  买入成本 = (旧成本 × 旧自有 + 本次入库量 × 入库价) / (旧自有 + 本次入库量)
自有 > 0 时卖出 / 提现：
  自有 = 旧自有 − 出库量（不截 0）
  仍 > 0：买入成本不变；= 0：清空；< 0：打负的那部分按本次出库价起卖出成本
自有 < 0 时卖出 / 提现：
  卖出成本 = (旧卖出成本 × |旧自有| + 本次出库量 × 出库价) / (|旧自有| + 本次出库量)
自有 < 0 时买入 / 充值：
  自有 = 旧自有 + 入库量
  仍 < 0：卖出成本不变；= 0：清空；> 0：打正剩下的部分按本次入库价起买入成本
```

### 四张主卡

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 做市账户余额 | 做市账上能用来挂买单的 USDT | 真实 USDT + 借入 USDT |
| 　自有 · 借入虚增 | 余额拆开 | 真实 USDT（买卖只改这一栏，可以为负）/ 借入 USDT（只有再借入才加，只有还款才减） |
| 可周转库存 | 做市账上能拿去挂单的代币 | 自有库存 + 借入虚增。自有可以为负，此时由虚增撑周转 |
| 平台用户USDT | 真实用户手里的现金 | 所有真实 UID 的 USDT 余额合计。不含做市 / 金库 / 项目方 / 员工 / LP |
| 平台用户代币 | 真实用户手里的该币 | 所内该币余额 − 做市可周转库存 − 金库 / 项目方 / 员工 / LP |
| 　活跃 · 沉睡 | 用户代币再拆 | 活跃 = 距最近一笔该币成交 < 30 天（或页面配置天数）的真实 UID 持仓合计。沉睡 = 其余真实 UID 持仓合计 |

### 今日交易情况（做市视角）

只计做市 UID 与真实用户的成交。自成交不进。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 卖出 数量 / 金额 / 均价 | 做市把货卖给真实用户 | 当日对真实用户卖出合计。金额 = 数量 × 均价。均价 = 卖出成交额 / 卖出量 |
| 买入 数量 / 金额 / 均价 | 做市从真实用户手里把货买回来 | 当日对真实用户买入合计。金额 = 数量 × 均价。均价 = 买入成交额 / 买入量 |
| USDT 净增加 | 这一天对用户成交让做市 USDT 多了还是少了 | 卖出金额 − 买入金额。正数 = 货换成了钱 |
| 代币净变动 | 这一天对用户成交让做市库存多了还是少了 | 买入量 − 卖出量。正数 = 货变多。不拿去算存货浮盈 |
| 平均价格 | 净头寸是按什么价换的 | `USDT净增加 / 代币净变动`。净变动为 0 时显示 `--` |

### 价格台阶预览

七档固定：+20% / +10% / +5% / 现价 / −5% / −10% / −20%。本页只预览挂单厚度，没有预估卖出。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 台阶 | 相对现价的位置 | 上面七档 |
| 价格 | 这一档对应的盘面价 | `现价 × (1 + 台阶%)` |
| 挂单 | 这一档自己的真实挂单量 | 本档累积 − 更靠近现价那一档的累积。现价档为 0 |
| 挂单金额 | 上一格换成 USDT | 挂单量 × 该档价格 |
| 累积 | 从现价扫到这一档会碰到的真实挂单 | 往上累真实用户卖单（卖墙），往下累真实用户买单（买墙）。现价为 0。不含做市自挂 |

### 供给位置

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 所内流通 | 已经在交易所、能成交的货 | 活跃用户代币 + 沉睡用户代币 + 做市可周转库存 |
| 活跃 / 沉睡 / 做市 | 所内流通三截 | 活跃、沉睡见上面主卡；做市 = 自有 + 虚增 |
| 链上仓库 | 还在链上、本所成交不到的货 | 总流通 − 所内流通 |
| 可充回 | 链上仓库里相对活跃、随时可能充进来的 | 未锁仓、近期还有过充提或转账的量（没有链上活跃标记时用估计） |
| 沉睡（链上） | 链上长期不动的 | 链上仓库 − 可充回 |

链上不能成交。货要充进所内，才变成可卖供给。

### 报警

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 时间 / 级别 / 内容 | 待处理警报摘要 | 级别：紧急（立刻处理，例如超大充提、大单、做市余额过薄）/ 预警（越过阈值，例如 OBI 失衡、偏离进压力区）/ 关注（持续盯盘，例如聪明钱净买）。状态不是「已处理」的才出现在这里 |

## 价格台阶

看：到某个价，外面挂了多少单、用户可能再卖多少、盘口偏买还是偏卖、有没有大单。路径 `/ops/ladder`。

本页单位：数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。金额 = 数量 × 价格。

本页「真实用户」= 所内会买卖的对手盘 UID，去掉做市 / 金库 / 项目方 / 员工 / LP。挂单、大单、持仓均价都只算真实用户。

```
用户买入 = 做市卖出
用户卖出 = 做市买入
```

### 状态行

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 现价 | 当前盘面价 | 最近一笔成交价；没有成交用最新中间价 |
| 用户均价 · 偏离 · 压力区 | 对手成本，现价离它多远 | 用户均价 = 群体持仓均价，算法见下。偏离 = `(现价 − 持仓均价) / 持仓均价 × 100`。进压力区 = \|偏离\| ≥ 偏离预警 |
| 做市库存成本 · 偏离 | 做市自有库存的成本 | 只滚自有。自有 > 0 买入成本，自有 < 0 卖出成本，自有 = 0 不显示。偏离 = `(现价 − 库存成本) / 库存成本 × 100` |

本页持仓均价（每个真实 UID，再合成群体）：

```
买入/充值按入库价加权，卖出/提现只减数量、不重算，数量不小于 0
入库后均价 = (旧均价 × 旧数量 + 本次入库量 × 入库价) / (旧数量 + 本次入库量)
入库价：买入 = 成交价；充值 = 到账时现价
出库后数量 = max(0, 旧数量 − 出库量)
群体持仓均价 = Σ(该 UID 剩余数量 × 该 UID 均价) / Σ剩余数量
```

本页做市库存成本：

```
只滚自有。虚增只有再介入才加、只有还款才减，买卖充提不动。自有可以为负。
自有 > 0：买/充值加权，卖/提现不改成本
自有 < 0：卖/提现按出库价滚卖出成本，买/充值只补缺口
自有 = 0：没有成本
入库价：买入 = 成交价；充值 = 到账现价
出库价（自有变负时）：卖出 = 成交价；提现 = 出金现价
```

### 台阶明细

七档固定：+20% / +10% / +5% / 现价 / −5% / −10% / −20%。现价是行为起点，这一档挂单为 0。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 台阶 / 价格 | 相对现价的位置和对应价 | `现价 × (1 + 台阶%)` |
| 真实挂单 | 从现价扫到这一档会碰到的真实单 | 往上：真实用户卖单累积（卖墙）。往下：真实用户买单累积（买墙）。现价 = 0。不含做市 |
| 金额（挂单旁） | 这些挂单值多少钱 | 挂单量 × 档位价 |
| 预估卖出 | 价格到了这一档，用户持仓里大概会再卖掉多少 | 不是挂单。对每个真实 UID：用该档价格相对他的持仓均价算偏离%，再按下面的卖出率 × 剩余仓位，最后加总 |
| 预估卖出金额 | 上一格换成 USDT | 预估卖出 × 该档价格 |
| 盈亏范围色条 | 预估卖出来自哪些盈亏带 | 按浮盈/浮亏分档：≥30%、20–30%、10–20%、5–10%、0–5%。色条占比 = 该带预估卖出 / 本档预估卖出合计 |

预估卖出率（浮盈、浮亏用绝对值，同一条曲线）：

```
x = |该档价相对该 UID 持仓均价的偏离%|
x = 0     → 卖 0
x ≤ 5%    → 从 0 线性到 10% 仓
x ≤ 10%   → 从 10% 线性到 20% 仓
x ≤ 30%   → 从 20% 线性到 30% 仓
x > 30%   → 卖 30% 仓
```

口算：浮盈/浮亏 5% 约卖 10% 仓，10% 约卖 20%，30% 约卖 30%。

| 至该价累计 | 从盘口扫到这个价会碰到多少 | 同一方向、价格不劣于该笔的所有真实挂单数量之和（同价几笔都算进去） |
| 账户 | 谁挂的 | UID 或脱敏展示 |
| 挂单时间 | 何时挂上 | 订单时间 |

## 做市账户 · 今日

自己今天买卖、库存、余额。点历史日期进来时，词改成「当日」，算法按那一天。路径 `/ops/dump`。

本页单位：数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。金额 = 数量 × 价格。

本页「真实用户」= 所内会买卖的对手盘 UID，去掉做市 / 金库 / 项目方 / 员工 / LP。「做市账户」= 机器人配置里的做市 UID。

```
用户买入 = 做市卖出
用户卖出 = 做市买入
```

**交易相关数字只计做市与真实用户的成交。** 自成交、内部调仓、与金库等成交不进买 / 卖 / 均价 / 人数 / 笔数 / 对倒 / 盈亏 / 成交明细。

库存拆账：

```
可周转库存 = 自有 + 虚增
可周转 USDT = 真实 USDT + 借入 USDT
虚增代币 / 借入 USDT：只有再介入 / 再借入才加，只有还款才减。不介入、不还款则永远不变。买卖充提改不了它们。
自有代币 / 真实 USDT：买入、卖出、充值、提现只改这一栏，可以为负。
```

库存成本只滚自有，不把虚增按 0 或现价混进加权：

```
自有 > 0：买入成本。买/充值按入库价加权；卖/提现只减数量
自有 = 0：没有成本，不显示偏离
自有 < 0：卖出成本，也算成本。卖/提现按出库价加权；买/充值只补缺口

自有 > 0 时买入 / 充值：
  买入成本 = (旧成本 × 旧自有 + 本次入库量 × 入库价) / (旧自有 + 本次入库量)
自有 > 0 时卖出 / 提现：
  自有 = 旧自有 − 出库量（不截 0）
  仍 > 0：买入成本不变；= 0：清空；< 0：打负部分按本次出库价起卖出成本
自有 < 0 时卖出 / 提现：
  卖出成本 = (旧卖出成本 × |旧自有| + 本次出库量 × 出库价) / (|旧自有| + 本次出库量)
自有 < 0 时买入 / 充值：
  自有 = 旧自有 + 入库量
  仍 < 0：卖出成本不变；= 0：清空；> 0：打正剩下的部分按本次入库价起买入成本

入库价：买入 = 成交价（仅对真实用户）；充值 = 到账现价
出库价：卖出 = 成交价（仅对真实用户）；提现 = 出金现价
```

本页顶部现价 = 最近一笔成交价（没有成交用最新中间价）。

本页顶部库存成本 · 偏离：上面滚出来的库存成本。偏离 = `(现价 − 库存成本) / 库存成本 × 100`。自有 = 0 不显示。

本页顶部用户均价：每个真实 UID 买入/充值加权、卖出/提现只减数量，再按剩余数量合成群体持仓均价。偏离 = `(现价 − 群体持仓均价) / 群体持仓均价 × 100`。

| 持仓用户 | 有仓人数 | 真实 UID、余额 > 0 |

## 单 UID

查一个真实用户。可切「当前代币」或「全部代币」。全部代币时，买卖数量改成万 USDT。路径 `/desk/user`。

本页单位：当前代币下，数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。全部代币下，买卖用万 USDT。金额 = 数量 × 价格。

本页对象必须是真实用户 UID。做市 / 金库 / 项目方 / 员工 / LP 不从这里查。

该 UID 每个币的持仓均价：

```
买入/充值按入库价加权，卖出/提现只减数量、不重算，数量不小于 0
入库后均价 = (旧均价 × 旧数量 + 本次入库量 × 入库价) / (旧数量 + 本次入库量)
入库价：买入 = 成交价；充值 = 到账现价
出库后数量 = max(0, 旧数量 − 出库量)
浮盈亏 = 持仓 × (现价 − 持仓均价)
```

现价 = 该币最近一笔成交价；没有成交用最新中间价。

成交只计该 UID 与做市的腿。自成交、内部调仓不进。

## 机器人 · 运行状态

做市 UID 现在挂得怎样。路径 `/robots`。

本页单位：数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。金额 = 数量 × 价格。1 bps = 0.01%。

本页「做市账户」= 机器人配置里的做市 UID。「真实用户」= 去掉做市 / 金库 / 项目方 / 员工 / LP 的对手盘。

```
用户买入 = 做市卖出
用户卖出 = 做市买入
```

交易相关数字只计与真实用户的成交。自成交只撑盘口，不进成交额、买卖比、盈亏。

库存：

```
可周转库存 = 自有 + 虚增
虚增：只有介入才加、还款才减；买卖不动
自有：买卖充提只改它，可以为负
```

库存成本只滚自有：自有 > 0 买入成本，自有 < 0 卖出成本，自有 = 0 没有。

盈亏：

```
交易盈亏 = min(买入量, 卖出量) × (均卖 − 均买)     // 买/卖只含对真实用户
存货浮盈 = 当前自有 × (现价 − 库存成本)           // 全部自有，不是当天净变动
今日盈亏 = 交易盈亏 + 存货浮盈
现价 = 最近一笔成交价；没有成交用最新中间价
```

所内流通 = 活跃真实用户代币 + 沉睡真实用户代币 + 做市可周转库存。活跃 / 沉睡按距最近成交是否 ≥ 30 天（或页面配置）。

| 做市库存 | 可周转库存 | 自有 · 借入虚增。占所内流通 40%–60% 为安全，低于偏低、高于偏高 |

## 金库等

另一本账：金库 / 项目方 / 员工 / LP。不能直接拿去买卖。可周转的代币和 USDT 在做市账户。做市 UID 在本页只能看、不能从这里删。路径 `/chips/internal`。

本页单位：数量 **万枚**，金额 **万 USDT**，价格 **USDT / 枚**。

现价 = 最近一笔成交价；没有成交用最新中间价。

所内流通 = 活跃真实用户代币 + 沉睡真实用户代币 + 做市可周转库存。总流通为发行口径。

做市在本页的数：

```
可周转库存 = 自有 + 虚增
做市账户余额 = 真实 USDT + 借入 USDT
虚增 / 借入 USDT：只有介入才加、还款才减
自有 / 真实 USDT：买卖充提只改它，可以为负
库存成本只滚自有：> 0 买入成本，< 0 卖出成本，= 0 没有
浮盈亏 = 自有 × (现价 − 库存成本)
```

金库 / 项目方 / 员工 / LP 用自己的移动加权成本：买入/充值按入库价加权，转出/提现只减数量、不重算。没有虚增。

| 名词 | 含义 | 怎么算 |
| --- | --- | --- |
| 内部合计 | 做市 + 金库等 | 占流通 % = 内部合计 / 总流通 × 100。数量为万枚 |
| 金库等 | 不含做市的内部持仓 | 金库 + 项目方 + 员工 + LP |
| 做市账户（可点进） | 可周转库存 / 做市账户余额 | 自有 + 虚增；真实 USDT + 借入 USDT |
| 锁仓/归属占比 | 金库等里短期拿不走的 | 状态带「锁」的持仓 / 金库等合计 |
| 自有近30日 | 金库等占比、数量 30 日变化 | 期末 − 期初 |
| 　做市库存近30日 | 做市可周转库存占比、数量变化 | 期末 − 期初 |
| 内部构成 | 饼图 | 做市（含虚增）+ 平台金库 + 项目方 + 内部人员 + LP 底池 |
| 做市库存 vs 安全带 | 库存占所内流通 | 做市可周转库存 / 所内流通。安全 40%–60% |
| 近期内部调仓 | 内部 UID 之间转货 | 时间、从、到、数量、原因。内部调仓不进做市交易统计 |
| 明细 UID / 备注 / 类型 | 配置的内部账 | 类型中文：做市账户 / 平台金库 / 项目方 / 内部人员 / LP 底池 |
| 口径 | 含虚增 或 自有 | 做市 = 自有 + 虚增；其余 = 自有 |
| 持仓 / 占内部比 | 该 UID 有多少 | 占内部比 = 该 UID 持仓 / 内部合计 |
| 成本 | 该 UID 的成本 | 做市：库存成本（只滚自有，空头为卖出成本）。金库等：自己的移动加权 |
| 浮盈亏 | 相对现价 | 做市：自有 × (现价 − 库存成本)。金库等：持仓 × (现价 − 该 UID 成本) |
| 最近调仓 / 状态 | 何时转过货、是否锁定 | |
